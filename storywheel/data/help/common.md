# Keys every mode shares
The keys that work the same everywhere.
## Keys
### common | Moving between modes
modes: Go to the Wheel (F1), Builder (F2), Writer (F3), Settings (F4) or Words (F5). The key of the mode you are in opens its help.
help: Open the help for this mode (it has a search box; Esc closes it)
back_mode: Back to the mode you came from, or close the panel or dialog you are in (your work is saved)
quit_program: Quit storywheel (asks first; everything is saved)
